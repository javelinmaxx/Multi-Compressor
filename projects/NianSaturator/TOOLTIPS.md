# Nian Saturator hover hints

| Control | Hint |
|---|---|
| Mode | Selects automatic narrow peak enhancement or conventional drive. |
| Crossover | Sets the frequency where the low and high bands meet. |
| Low | Sets the low-band peak enhancement or drive. |
| High | Sets the high-band peak enhancement or drive. |
| Output | Adjusts the final stereo output level. |
| Bypass | Bypasses processing while preserving the plugin's latency. |
