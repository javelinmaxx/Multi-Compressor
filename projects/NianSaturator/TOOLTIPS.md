# Nian Saturator hover hints

| Control | Hint |
|---|---|
| Mode | Selects short twelve-band transient enhancement or dynamically softened tube-style drive. |
| Crossover | Sets the low/high split on a logarithmic frequency scale. |
| Low | Sets the low-band peak enhancement or drive. |
| High | Sets the high-band peak enhancement or drive. |
| Mix | Blends the processed sound with the latency-aligned original. |
| Output | Adjusts the final stereo output level. |
| Bypass | Bypasses processing while preserving the plugin's latency. |
| Signal display | Click to audition only the generated delta, or drag the gold crossover line to change the split frequency. |
