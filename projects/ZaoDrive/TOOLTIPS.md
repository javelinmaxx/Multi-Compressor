# Zao Drive hover hints

![Zao Drive with the circuit hint visible](Previews/zao-tooltip.png)

| Control | Hover hint |
| --- | --- |
| Plugin title | Developer: J-Sonic Team; Year: 2026; Version: 0.7.5 |
| Smart | Saves CPU when Off; reduces generated harmonics that clash with the input spectrum. |
| Clear | Saves CPU when Off; applies the octave-shifted equal-loudness contour without frequency boosts. |
| Circuit | Selects BJT, op-amp feedback, diode shunt, or series-diode crossover distortion. |
| BJT Bias | Shifts the BJT base-bias voltage away from its nominal operating point. |
| Diode Knee | Increases amplifier output impedance and softens current delivery into the Schottky diodes. |
| Op-Amp Input | Adjusts the level entering the selected circuit after optional Clear shaping. |
| Drive | Increases the signal driving the selected overdrive circuit after optional Clear shaping. |
| Tone | Sets the low-pass cutoff of the driver-minus-reference wet signal. |
| Auto | Matches the preview RMS before applying the Output knob as a gain offset. |
| Output | Adjusts gain before the transformer and offsets the matched level when Auto is enabled. |
| Mix | Adds the driver-minus-reference wet signal to the latency-aligned clean input. |
| Core drive | Increases saturation in the enabled output transformer. |
| DC bias | Adds transformer asymmetry to increase even harmonics. |
| Transformer | Saves CPU when Off; adds Yinyang's transformer coloration when On. |
| Bypass | Bypasses the overdrive and transformer while preserving plugin latency. |
