# Qin Synth control hints

| Control | Hint |
| --- | --- |
| Plugin title | Developer: J-Sonic Team; Year: 2026; Version: 0.7.5 |
| Sound tab | Shows the three oscillator tabs and their sound controls. |
| FX tab | Shows the voice, drive, and delay-reverb controls. |
| Voice + Drive tab | Shows voice shaping, key panning, Zao Drive, and output. |
| Delay-Verb tab | Shows Lan's delay-reverb and MIDI onset motion controls. |
| Osc 1 tab | Opens oscillator 1 in the Sound editor. |
| Osc 2 tab | Opens oscillator 2 in the Sound editor. |
| Osc 3 tab | Opens oscillator 3 in the Sound editor. |
| Osc 1 Wave | Chooses the first oscillator's band-limited virtual-analog waveform. |
| Osc 1 Level | Sets the first oscillator's level. |
| Osc 1 Octave | Moves the first oscillator by whole octaves. |
| Osc 1 Unison | Sets up to eight unison copies for the first oscillator. |
| Osc 1 Detune | Spreads the first oscillator's unison copies in cents. |
| Osc 2 Wave | Chooses the second oscillator's band-limited virtual-analog waveform. |
| Osc 2 Level | Sets the second oscillator's level. |
| Osc 2 Octave | Moves the second oscillator by whole octaves. |
| Osc 2 Unison | Sets up to eight unison copies for the second oscillator. |
| Osc 2 Detune | Spreads the second oscillator's unison copies in cents. |
| Osc 3 Wave | Chooses the third oscillator's band-limited virtual-analog waveform. |
| Osc 3 Level | Sets the third oscillator's level. |
| Osc 3 Octave | Moves the third oscillator by whole octaves. |
| Osc 3 Unison | Sets up to eight unison copies for the third oscillator. |
| Osc 3 Detune | Spreads the third oscillator's unison copies in cents. |
| Attack | Sets the time for a new note to reach full level. |
| Release | Sets how long a note fades after release. |
| Key Pan | Places lower MIDI notes left and higher notes right, like a piano recording. |
| Zao Drive | Blends in Zao's op-amp feedback clipping circuit. |
| Output | Adjusts the instrument's output gain. |
| Time | Sets the base delay time of Lan's feedback network. |
| Decay | Sets how long Lan's delay-reverb tail decays. |
| Scatter | Moves Lan's feedback from delay toward diffuse reverb. |
| Mix | Blends the delay-reverb with the synth signal. |
| Tap Motion | Sets how far each MIDI note-on shifts Lan's feedback taps. |
| Phase Motion | Sets how strongly each MIDI note-on changes Lan's phase scatter. |
