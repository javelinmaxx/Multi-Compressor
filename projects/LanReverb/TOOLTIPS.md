# Lan Reverb hover hints

| Control | Hint |
|---|---|
| Time | Sets the repeat time or room size in milliseconds, or selects a musical note length when Sync is on. |
| Sync | Synchronizes Time to the DAW tempo using straight, dotted or triplet note lengths. |
| Decay | Sets the nominal feedback decay time before filtering, while shelf boost can sustain an indefinite tail. |
| Pre-delay | Delays the signal entering the reverb while leaving the dry signal immediate. |
| Scatter | Morphs aligned delay repeats at zero into a dense stereo reverb at full. |
| Diffusion | Adjusts the mixing density of the feedback network as Scatter increases. |
| Width | Sets the stereo spread of the wet signal with a normalized mid and side balance. |
| Tap Shift | Moves the feedback read taps through a 250-millisecond crossfade to scatter existing ringing frequencies. |
| Phase | Sets feedback phase dispersion and correction across three resonance bands within a five-millisecond delay budget. |
| Tame | Sets narrow feedback resonance attenuation within a shared six-decibel limit while protecting incoming notes. |
| Shimmer | Adds an octave-up input layer to the feedback-loop injection using a twice-oversampled pitch shifter; Saves CPU when Off. |
| Low shelf handle | Drag horizontally for shelf frequency and vertically for gain, or double-click to reset the shelf. |
| High shelf handle | Drag horizontally for shelf frequency and vertically for gain, or double-click to reset the shelf. |
| Dry / Wet | Blends the immediate dry signal with the reverb and reaches a fully wet output at one hundred percent. |
| Output | Adjusts the final output level after the dry and wet signals are mixed. |
| Auto | Compares spectral peaks and frequency decay rates to guide input-protected feedback correction; Saves CPU when Off. |
| Bypass | Bypasses the output while keeping the reverb and resonance analysis running for a smooth return. |
| Plugin title | Developer: J-Sonic Team; Year: 2026; Version: 0.5.0 |
